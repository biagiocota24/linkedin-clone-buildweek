# LinkedIn Clone – Build Week EPICODE

Clone di LinkedIn sviluppato in team di 5 persone in una settimana,
durante il percorso Full-Stack Developer di EPICODE (maggio 2026).

**Stack:** React · TypeScript · Redux · React Router · Bootstrap

## Il mio contributo
- Home page: feed centrale, sidebar e contenuti consigliati
- Sezione Lavoro: elenco offerte e pagina di dettaglio
- Dettaglio notizie, sezione giochi
